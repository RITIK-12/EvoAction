EvoAction evidence report

A self-evolving, recursively delegated annotation harness for robot manipulation video, evaluated on WGO-Bench temporal subtask segmentation with Macrodata's protocol. Every number and agent message on this page comes from persisted real runs in artifacts/.

1. Results: Macrodata's metric on the same episodes for every version

Headline metric follows Macrodata's WGO-Bench evaluation: temporal IoU ≥ 0.75, one-to-one maximum matching, pooled over episodes, with the first predicted start and last predicted end snapped to the human episode boundaries (scoring-only); labels are ignored. Every version in a batch runs on exactly the same episodes. Ground truth is measured by the protected evaluator for this table only; agents and the promotion gate never see it.

2. Human-in-the-loop: 10% labeled sample shared with the agents

As in production annotation, humans label a small sample after each pass. Here a fixed ~10% of each batch (whole instruction groups, chosen before the run) is labeled: agents see those human segments next to the incumbent's predictions, and the gate promotes only if Segment F1@0.75 on that sample strictly improves. The other 90% are never labeled for agents or the gate; their score is the honest measure of whether the fix generalized.

2. Version N → N+1 lineage (label-free gate)

Agents and the promotion gate see no ground truth: only the system's own predictions, video frames, robot telemetry and a predeclared label-free self-score. "Shadow GT" is measured by the protected evaluator after each decision and is never shown to agents or the gate. Rejected candidates are frozen, not deleted.
